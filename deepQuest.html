DeepQuest

Problem statement

Many tertiary students struggle to manage multiple modules, each with different assignments, deadlines, and study tasks. Remembering and prioritizing these tasks can be overwhelming, often leading to missed deadlines, poor time management, and increased stress. Existing task management tools are either too complex or not tailored to students' academic needs, making them ineffective for consistent use.

Technologies Used

  • React

Proposed Solution

DeepQuest is a secure, student-focused web application that helps students organize and manage their study tasks efficiently. With user authentication, students can create, view, edit, filter, and delete tasks based on their modules and priorities through an intuitive interface supported by a robust API. By centralizing all academic tasks on one platform, DeepQuest helps students stay organized, reduce stress, and maintain consistency in their learning.

Features

  • Secure Authentication: User registration and login with JWT token validation and dual storage (cookies + localStorage).
  • Task Creation: Add study tasks with complete details, title, subject, description, deadline, priority level, and status tracking.
  • Task Viewing: Display all tasks with advanced filtering options by priority and completion status.
  • Task Editing: Modify existing task information or update completion status directly.
  • Task Removal: Delete unwanted tasks with user confirmation dialog for safety.
  • Smart Filtering: Comprehensive controls including status filters, priority sorting, full-text search across title/subject/description, and custom sort orders.
  • View Overdue Tasks: Dedicated Overdue Tasks page that automatically detects tasks past their deadline and lists them for follow-up.
  • Enhanced UX: Bonus features include interactive Study Helper chat widget, Shimmer loading states, animated reviews marquee, and persistent cookie sessions.

Workflow

  • Landing page (/) automatically forwards to authentication screens.
  • Registration/Login captures JWT credentials stored securely in browser storage.
  • Dashboard (/home) provides task preview with intelligent priority-based organization.
  • Main Tasks (/studytasks) offers complete management, search, filter by status/priority, edit inline, delete with confirmation.
  • Overdue Tasks (/overdue-tasks) shows only tasks whose deadline has passed using shared API and date utility.
  • Create/Edit forms include full validation, sync seamlessly with backend API, then redirect back to task overview.
  • Logout completely clears authentication state and returns to login screen.
